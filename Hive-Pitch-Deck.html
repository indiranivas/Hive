Knowledge graph · Neo4j

Everything linked in one graph.

The graph model

  • (Person)-[:KNOWS]->(Topic)
  • (Person)-[:AUTHORED|REVIEWED]->(Artifact)
  • (Artifact)-[:IN_REPO]->(Repo)
  • (Person)-[:ASKED|ANSWERED]->(KR)
  • (Person)-[:COLLABORATES_WITH]->(Person)
  • (Repo)-[:COUPLED_WITH]->(Repo)

Cypher: topics that rest on one person

MATCH (p:Hive {kind:'person'})
      -[r:REL {kind:'KNOWS'}]->
      (t:Hive {kind:'topic'})
WITH t, collect(p) AS knowers
WHERE size(knowers) = 1
RETURN t.label AS bus_factor_risk

Neo4j via Bolt or Aura's HTTPS Query API, with an in-memory fallback.
